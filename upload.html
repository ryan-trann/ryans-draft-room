Upload your complete Hashtag Basketball projection table once. The saved file lives in your GitHub repository, and everyone using the Draft Room loads that same projection data. Your draft picks stay local to each device.

2. Authorize one GitHub upload

Generate a fine-grained personal access token in GitHub Settings → Developer settings → Personal access tokens. Limit repository access to ryan-trann/ryans-draft-room and grant Contents: Read and write. You can set a short token expiration. The token is used for this upload only, cleared from the form, and never saved to your browser's storage or the repository.

Nothing will be uploaded until you confirm.
