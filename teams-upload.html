Restore or replace saved teams

Upload a Draft Room JSON backup to store its 12 rosters permanently in GitHub. The existing shared team file is replaced only after validation and your authorization. The latest projections are used to identify individual players—even when names are abbreviated.

1. Select your original draft backup

Choose your downloaded draft-backup JSON file.

2. Publish to GitHub

Use the same restricted GitHub token as for projection uploads (repository Contents: Read and write). The token is never saved and the entry field is cleared after an attempt.

Validate a complete draft before publishing.
